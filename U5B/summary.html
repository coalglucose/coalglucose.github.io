Quick Summary:

  • Use sample data to determine whether there is convincing evidence for a claim about a population parameter.
  • H0​: The default assumption; represents no difference or no effect and contains equality.
  • Ha: The claim we are trying to support; uses <, >, or neq
  • P-value: Reject H0 if p < alpha
  • Type I Error: Rejecting a true H0 (false positive), denoted alpha
  • Type II Error: Failing to reject a false H0​ (false negative), denoted beta
  • Power: 1 - beta, a way to the strength of your test
  • Increasing Power: Increase the sample size, increase alpha, reduce variability, or have a larger true effect.
