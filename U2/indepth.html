Unit 2: Two-Variable Data

This unit will be covering bivariate data, which involve manipulating an explanatory (independent) variable and getting a response (dependent) variable.

DISPLAYS

Just like in U1, we have multiple methods of displaying two-variable data. The bulk of U2 involves scatter plots, which are only usable for quantitative data. The value of the eXplanatory variable is plotted along the x-axis, and correspond to a response variable along the y-axis. The relationship between the explanatory and response variables is also known as association [right..?].

When describing a scatter plot, as with any display of data, add context (!!!) and talk about strength, direction, form, and unusual features.

> Strength is pretty straightforward. The clearer the pattern, the stronger the association is. Note it is possible for an association to be so weak we can say there is “no association.” That doesn’t come up often though, because it wouldn’t make much sense to talk about the rest of the characteristics and do a weaker job of testing students.

> Direction refers to the type of association: positive (as x increases, so does y) or negative (as x increases, y decreases).

> Form is analogous to shape. A scatterplot can be linear or non-linear, and if it’s curved, you can also say it is curvilinear.

> Unusual features can be outliers, distinct clusters of points, gaps, or anything that looks weird (unusual, even).

COEFFICENT OF CORRELATION AND DETERMINATION

Correlation (r) quantifies the strength and direction of a linear relationship between two variables (remember, these variables must be quantitative). The sign of r matches the association, and the higher |r| is, the stronger the linear relationship is.

For variables x and y, the correlation is defined as

        r = (sum(zx*zy) / N) [z-scores, N vs n-1]

You don’t need to memorize this, you’ll either use a calculator or be given it. But being familiar with the formula will help in understanding a few key traits about r: it is unitless and affected by outliers (non-resistant, and strongly so).

  1. High leverage points are far in x-value from the rest of the dataset
  2. Influential points:  any point that, if removed, would modify the regression line significantly. These often have high leverage, but not always.

Often, we will have a certain number of data points but need a specific value that is not present on the scatter plot. We then need to predict the value based on the ones we have. But we will rarely be exactly correct in our prediction, and the error of the model is called the residual: y - y-hat.

Notice that if the residual is positive, y>y-hat so the model was an underestimation; if the residual is negative, y<y-hat so the model overestimated.

The coefficient of determination = r2, and as a percentage, it captures how much of the variation between x and y can be explained by their linear relationship.

Residual plots graph the residuals on the y-axis against the explanatory variable on the x-axis, and they’re essential for determining if linear models are appropriate for a dataset. We want a residual plot that has a random scatter of points, no clear shape or pattern.

LEAST-SQUARED RESIDUAL LINES

LSRLs are the line of best fit, where the sum of the squared residuals are minimized.
