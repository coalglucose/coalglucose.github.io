Chapter 1
One-Variable Data
Introduction: Statistics

Statistics is the science and art of collecting, analysing, and drawing conclusions from data.

Types of Variables
  • Categorical — Nominal: has a certain order
  • Categorical — Ordinal: no particular order
  • Note: numbers can be categorical if they don't measure anything (e.g. cell phone digits)
  • Quantitative — Discrete: fixed set of possible values with gaps; whole numbers; countable
  • Quantitative — Continuous: infinite possibilities; decimals/fractions; any value in an interval
The key distinction: whether the variable measures something.
Basic Vocab
  • Individual: object described in the data (also: cases, observational units)
  • Variable: aspect that can take different values for different individuals
  • Distribution: pattern of variation — what values a variable takes and how often
  • Descriptive statistics: analysing data (Units 1–7)
  • Inferential statistics: drawing conclusions from data (Units 8–12)
1.1 · Analysing Categorical Data
One-Variable Categorical — Tables
  • Frequency table
  • Relative frequency table
One-Variable Categorical — Graphs
  • Bar graph: equal-width bars, leave gaps, label & scale axes, frequencies or relative frequencies (specify which)
  • Pie chart: good for comparing categories to the whole; slices proportional to frequencies; must include all categories; include a legend
Two-Variable Categorical — Tables

Two-way table summarises the relationship between two categorical variables.

Key frequency types:
· Marginal relative frequency: row or column total ÷ grand total
· Joint relative frequency: cell ÷ grand total
· Conditional relative frequency: cell ÷ row or column total
Two-Variable Categorical — Graphs
  • Side-by-side bar graph: bars showing one variable for each value of another; acceptable for bars to touch within groups, but leave space between groups
  • Segmented bar graph: stacked bars proportional to relative frequencies; uses relative frequencies; bars do not touch
  • Mosaic plot: like segmented but bar width is proportional to number of individuals; bars do touch
Tables are summaries of data, not data themselves. Avoid truncating axes and using pictograms.

Association: knowing one variable lets you predict the other. Association ≠ causation.

1.2 · Displaying Quantitative Data with Graphs

Main graph types: dotplot, stemplot, histogram, boxplot

Histogram Tips
  • Equal-size bins; aim for at least 5
  • Bars touch; use frequencies or relative frequencies (specify!)
  • Use relative frequencies when comparing distributions with different n
  • Right edge of bin is typically non-inclusive
Stemplot Tips
  • Stem = all but final digit; leaf = final digit
  • Split stems if needed (aim for ≥ 5 stems with equal possible leaf digits)
  • Back-to-back stemplot for two groups; always add a key

Always add context — variables and units!
1.3 · Describing Quantitative Data with Numbers
Measures of Center
  • Mean (x̄ or µ): average — non-resistant
  • Median: middle value — resistant
  • Mode: most common value
Measures of Variability
  • Range: easy to calculate; non-resistant
  • IQR: middle 50%; resistant. Calculate quartiles by splitting each half (exclude median)
  • Standard deviation (sx or σ): typical distance from mean. Non-resistant. Use only with mean.
sd formula: √[ Σ(xi − x̄)² / (n − 1) ] outlier rule: below Q1 − 1.5·IQR OR above Q3 + 1.5·IQR five-number summary: min, Q1, median, Q3, max
Choose measures based on whether resistancy is a concern for the distribution.
Statistic vs. Parameter
  • Statistic: describes a characteristic of a sample
  • Parameter: describes a characteristic of a population

Chapter 2
Modeling Distributions of Quantitative Data
2.1 · Describing Location in a Distribution
  • Percentile: pth percentile = value with p% of observations ≤ it. Allows comparison across different distributions.
  • Cumulative relative frequency graph (ogive): plots percentile of each value; points connected with line segments
  • Z-score: (value − mean) / sd — how many SDs from the mean (and in which direction)
Transforming Data
  • Adding/subtracting a constant: affects center/location only (not shape or variability)
  • Multiplying/dividing by a constant: affects center, location, and variability (not shape)
  • Z-score distribution: same shape as original; mean = 0; SD = 1
2.2 · Density Curves & Normal Distributions

A density curve is always on or above the horizontal axis and has area = 1 underneath. It is always an approximation.

Normal Distributions

Bell-shaped, symmetric, unimodal. Fully described by mean (µ) and SD (σ).

Empirical Rule: 68% of values within 1σ of µ 95% of values within 2σ of µ 99.7% of values within 3σ of µ
Finding Areas
  1. Apply empirical rule (when applicable)
  2. Find z-score → use Table A for p-value (area to the left)
  3. Use technology (always label values on the FRQ!)
Assessing Normality
  • Plot data and see if it looks normal
  • Check against empirical rule (within 3–5% is good)
  • Normal probability plot — look for a straight-ish line
Real-world data is always approximately normal — never perfectly normal.

Exploring Two-Variable Quantitative Data
3.1 · Scatterplots & Correlation

Explanatory variable → x-axis. Response variable → y-axis. You CAN truncate axes here.

Describing Scatterplots — CDOFS
Context

Outliers

Strength
Correlation Coefficient (r)
  • Measures strength and direction for linear relationships only
  • Non-resistant; no units; unaffected by changing units or swapping variables
  • Strength guide: |r| < 0.5 = weak · 0.5–0.75 = moderate · > 0.75 = strong
Correlation is NOT causation.

Extrapolation: using a regression line to predict well outside the range of observed x-values — unreliable because the linear relationship may not hold.

3.2 · Linear Regression
LSRL: ŷ = a + bx slope: b = r · (sy / sx) y-int: a = ȳ − b · x̄ (LSRL passes through (x̄, ȳ)) residual = actual − predicted sum of residuals on LSRL = 0
Key Statistics
  • s (SD of residuals): typical distance between predicted and actual values. Calculated like SD but divide by n−2.
  • r² (coefficient of determination): percent of variability in y explained by the linear association with x. The percent reduction in sum of squared residuals vs. using the mean.
Influential Points
  • Outlier: large residual; doesn't follow the pattern
  • High leverage point: extreme x-value; often influential
  • Removing outliers usually increases r, r², and improves s, but doesn't strongly affect the LSRL
FRQ Interpretation Templates
  • Slope: "For every [1 unit] increase in [x], there is a predicted [increase/decrease] of [b units] in [y]."
  • r²: "[r²]% of the variability in [y] can be explained by the linear association with [x]."
  • s: "On average, the model mispredicts [y] by [s units]."
  • Residual plot: "The residual plot [is randomly scattered / shows a pattern], indicating a linear model [is / is not] appropriate."
Always write ŷ (hat) for predicted values and always say "predicted."
3.3 · Transforming to Achieve Linearity
  • Power models (y = axᵖ): use log-log transformation (log both variables)
  • Exponential models (y = abˣ): take log of y-variable only
  • Choosing a model: most random scatter in residual plot; tiebreaker = highest r²

Chapter 4
Collecting Data
4.1 · Sampling & Surveys
Sampling Methods
  • SRS: every group of n individuals has an equal chance. Sample without replacement.
  • Stratified: SRS from each stratum (groups with similar characteristics). More precise estimates.
  • Cluster: randomly select entire clusters. Resource-efficient; no statistical advantage.
  • Systematic: random start, every kth individual. Useful when population size is unknown.
Sources of Bias
  • Voluntary response bias: individuals who feel strongly are more likely to respond
  • Undercoverage: certain individuals less likely to be chosen
  • Nonresponse: selected individual can't be contacted or refuses
  • Response bias: systematic inaccurate answers (wording, order of questions)
4.2 · Experiments
Key Vocabulary
  • Treatment: condition imposed on individuals
  • Factor: explanatory variable that is manipulated
  • Experimental unit / Subject: individual to which treatment is applied
  • Confounding: variables whose effects on the response can't be distinguished from one another
  • Placebo / Blinding: double-blind = neither subjects nor measurers know treatment; single-blind = one group knows
Requirements for a Good Experiment
  • Control group — baseline for comparison
  • Random assignment — avoids confounding
  • Control — all other variables constant
  • Replication — enough subjects to distinguish effects from chance
Experiment Designs
  • Completely randomized design: units assigned to treatments fully at random
  • Randomized block design: random assignment within blocks (groups similar in a way that affects response)
  • Matched pairs: type of RBD; pairs of similar units or each individual receives both treatments in random order

Chapter 5
Probability
5.2 · Probability Rules
P(A) = outcomes in A / total outcomes P(Aᶜ) = 1 − P(A) General addition: P(A or B) = P(A) + P(B) − P(A and B) Mutually exclusive: P(A or B) = P(A) + P(B) General multiplication: P(A and B) = P(A) · P(B | A) Independent events: P(A and B) = P(A) · P(B)
  • Mutually exclusive (disjoint): P(A and B) = 0 — cannot occur simultaneously
  • Independent: P(A | B) = P(A) — knowing one doesn't change the probability of the other
Mutually exclusive events are automatically NOT independent.
5.3 · Conditional Probability & Independence
P(A | B) = P(A ∩ B) / P(B)

Tree diagrams are especially useful for conditional probability problems with successive events.

When calculating probabilities without replacement, adjust all numbers for each trial.

Chapter 6
Random Variables & Probability Distributions
6.1 · Discrete & Continuous Random Variables
  • Discrete: fixed set of values with gaps; described by probability distributions and histograms
  • Continuous: any value in an interval; individual outcomes have probability 0; use density curves
  • Mean (µx): expected value = Σ(xi · pi). Interpretation: average outcome over many trials.
  • SD (σx): √[Σ(xi − µx)² · pi]. Typical distance from the mean.
6.2 · Transforming & Combining Random Variables
For Y = a + bX: µY = a + b·µX σY = |b|·σX For X + Y (independent): µX+Y = µX + µY σX+Y = √(σX² + σY²) ← variances add, NOT standard deviations! For aX + bY (independent): µ = a·µX + b·µY σ = √(a²σX² + b²σY²)
X₁ + X₂ is NOT the same as 2X. Any linear combination of normal random variables is also normal.

Chapter 7
Sampling Distributions
7.1 · Sampling Distributions
  • Sampling distribution: distribution of a statistic across all possible samples of the same size from the population
  • Unbiased estimator: mean of sampling distribution = true parameter value
  • Bias: statistics consistently don't match parameters → check center
  • Variability: how spread out the statistics are → check SD
Sampling Distribution of p̂ (Proportions)
Conditions: Large Counts (np ≥ 10, n(1−p) ≥ 10) AND 10% condition Shape: ~Normal if large counts satisfied Center: µp̂ = p (unbiased) SD: σp̂ = √(p(1−p)/n)
Sampling Distribution of x̄ (Means)
Conditions: Normal condition AND 10% condition Normal condition: population is Normal OR CLT (n ≥ 30) Shape: ~Normal if condition met Center: µx̄ = µ (unbiased) SD: σx̄ = σ/√n

Chapter 8
Confidence Intervals for Proportions
Four-Step Process
  1. Choose: inference procedure, parameter, confidence level
  2. Conditions: Random, 10%, Large Counts (~normality)
  3. Calculate: confidence interval = point estimate ± margin of error
  4. Conclude: in context
Key Concepts
  • Confidence level C%: in C% of all possible samples, the interval will capture the true parameter
  • To decrease margin of error: decrease confidence level OR increase n
  • MoE only accounts for chance variation, not bias
FRQ Answer Templates
Confidence interval: "We are C% confident that the interval from ___ to ___ captures the true proportion of [context]."

Confidence level: "In C% of all possible samples, the interval computed will capture the true [parameter in context]."

Assessing a claim: "Since [value] [is / is not] in the confidence interval, we [do / do not] have convincing evidence that [claim in context]."
Always interpret parameters in conditional tense, not past tense!

Chapter 9
Significance Tests for Proportions
Four-Step Process
  1. Choose: inference procedure, parameter, hypotheses (always about population), significance level α
  2. Conditions: Random, 10%, LLC (use p₀ for LLC, not p̂)
  3. Calculate: sample statistic, standardized test statistic, p-value. Draw normal curve.
  4. Conclude: in context
z = (p̂ − p₀) / √(p₀(1−p₀)/n) Two-sided tests: double the p-value! Pooled proportion (two-sample): p̂c = (X₁ + X₂) / (n₁ + n₂)
Conclusion Template
"Assuming H₀ is true, the probability of obtaining results as extreme as or more extreme than what we observed is [p-value]. Since these results [are / are not] significant at α = [__], we [reject / fail to reject] H₀ — we [do / do not] have convincing evidence that [Hₐ in context]."
Error Types & Power
  • Type I error (α): rejecting a true H₀
  • Type II error (β): failing to reject a false H₀
  • Power (1 − β): probability of correctly rejecting H₀. Increases with larger n, larger α, or larger effect size.
  • Trade-off: as P(Type I) increases, P(Type II) decreases.
NEVER "accept the null hypothesis." You can only fail to reject it.

Confidence Intervals for Means
10.1 · Estimating a Population Mean
x̄ ± t* · (sx / √n) df = n − 1 Use Table B (round down if exact df not listed) or invT

t-distributions have more area in the tails than Normal to account for extra variability from estimating σ with sx.

Normal Condition (3 Ways to Satisfy)
  • CLT: n ≥ 30
  • Population distribution is approximately normal
  • Distribution of sample data appears approximately normal — plot and include the plot on the FRQ!
10.2 · Difference in Means
µdiff (matched pairs): use x̄diff and sdiff → 1-sample t-interval Two-sample: subtract means, add variances df: use technology (2SampTInt) or choose smaller df (more conservative)
For two-sample: define which mean is which and state your order of subtraction!

Chapter 11
Significance Tests for Means
Test Types
  • 1-sample t-test: significance test for one mean
  • 2-sample t-test: significance test for difference between two means
  • Paired t-test: for matched pairs experiment designs (use mean difference)
t = (x̄ − µ₀) / (sx / √n) Two-sided: double the p-value! Calculator: t-test, 2-samp t-test, tcdf(test statistic, upper bound, df)
Confidence intervals and two-sided significance tests at the (100 − α)% level generally lead to the same conclusion — but CIs provide more information (a range of plausible values).
Beware: statistical significance ≠ practical significance. Also watch for p-hacking.

Chapter 12
Inference for Distributions & Relationships
12.1 · Chi-Square Goodness of Fit

Tests whether a hypothesized distribution seems valid for a categorical variable with 2+ categories.

χ² = Σ [(observed − expected)² / expected] expected count for category i = n · pi df = (number of categories − 1) p-value: χ²cdf(test statistic, upper bound, df) LLC: all expected counts ≥ 5
  • H₀: hypothesized distribution is true
  • Hₐ: at least one category does not match the hypothesized value
  • χ² is always ≥ 0; distribution is right-skewed; mean = df
  • Follow-up analysis: if you reject H₀, identify which categories contributed most to χ² and describe how observed differs from expected
12.2 · Chi-Square Tests for Two-Way Tables
Test for Homogeneity

Compares the distribution of a single categorical variable across multiple populations or treatments (multiple independent samples).

  • H₀: no difference in true distribution between populations/treatments
  • df = (rows − 1)(columns − 1)
  • Expected value = (row total × column total) / grand total
Test for Independence / Association

Compares distributions of two categorical variables in a single population (one sample).

  • H₀: no association between variables in the population
  • Same formulas as homogeneity; distinguish by how data was collected
Homogeneity vs. Independence: If one set of marginal totals was fixed before data collection → homogeneity. If only the grand total was fixed → independence. Best method: look at how the sample was selected.
For a 2×2 table with a one-sided hypothesis: use a 2-sample z-test for p₁ − p₂, NOT a chi-square test. For a confidence interval on the difference: use 2-sample z-interval.
