General Rules:

  • Use population parameter symbols in your hypothesis tests
  • Use population parameter symbol for proportion test
  • Remember the difference between a sample and a sampling distribution
  • Use non-determinate language
  • Multiply p-value by 2 if working with two-tailed test

Hypothesis Testing:

  • H0 = what you’re trying to disprove
  • Ha = what you’re trying to prove

Three conditions:

  • Random sample - Ensures statistics are unbiased.
  • Normality
  • Success-Failure Condition if proportion
  • CLT or NPP if mean
  • Independence
  • 10% Condition

Sample proportion analysis:

  • Find zcv using calculator
  • z = (p̂ - p) / sqrt(pq/n)
  • Calculate p-value similar to normal distribution
  • Graph with zcv and z

Sample mean analysis (t-test):

  • Find tcv using calculator
  • t= (x̄ - μ) / (s/sqrt(n))
  • Calculate p-value similar to normal distribution
  • Graph with tcv and t
  • df = n - 1

Conclusion:

  • “Because my p-value < a, I reject/fail to reject the null hypothesis at the __ level of significance. This provides / does not provide sufficient evidence to support that the (repeat question statement with hypotheses tested)

Confidence Intervals:

Three conditions:

  • Random sample - Ensures statistics are unbiased.
  • Normality
  • Success-Failure Condition if proportion
  • CLT or NPP if mean
  • Independence
  • 10% Condition

Analysis:

  • CI = u +- tcv
  • Interpretation of confidence interval: “I am x% confident that the true proportion/mean lies within the interval (a, b). If I were to repeat this with the same exact method and sampling procedure, in the long run, x% of the intervals so generated would contain the true proportion/mean”
