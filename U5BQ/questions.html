Questions 11 and 12 are based off of the following information:

A website currently has a 75% pass rate for a practice quiz. A redesigned version is tested to see if it increases the pass rate. The hypotheses are H0: p = 0.75 and Ha: p > 0.75.

  1. Which is a Type I error?
            A. Concluding that the redesign increases the pass rate when the true pass rate is still 75%.
            B. Failing to conclude that the redesign increases the pass rate when the true pass rate is greater than 75%.
            C. Concluding that the redesign does not increase the pass rate when the true pass rate is exactly 75%.
            D. Collecting a sample that has a pass rate greater than 75%.

  1. Which is a Type II error?
            A. Concluding that the redesign increases the pass rate when it actually does not.

            C. Rejecting H0 when the p-value is less than alpha.
            D. Using a significance level that is too small.
