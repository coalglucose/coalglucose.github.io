General Rules:

  • Chi-squared tests compare observed and expected counts.
  • Chi-squared tests are always right-tailed.

Chi-Squared Goodness-of-Fit:

  • One sample, one categorical variable.
  • Tests whether a population follows a claimed distribution.
  • H₀: Population follows the stated distribution.
  • Hₐ: Population does not follow the stated distribution.
  • Assumptions: Random, Independent, 10% condition, Expected counts ≥ 5.
  • Expected count: E = np.
  • df = categories − 1.

Chi-Squared Test for Independence:

  • One sample, two categorical variables.
  • Tests whether two variables are associated.
  • H₀: Variables are independent.
  • Hₐ: Variables are associated.
  • Assumptions: Random, Independent, 10% condition, Expected counts ≥ 5.
  • Expected count = (Row Total × Column Total) ÷ Grand Total.
  • df = (rows − 1)(columns − 1).

Chi-Squared Test for Homogeneity:

  • Multiple samples, one categorical variable.
  • Tests whether population distributions are the same.
  • H₀: Population distributions are the same.
  • Hₐ: At least one distribution is different.
  • Assumptions: Random, Independent, 10% condition, Expected counts ≥ 5.
  • Expected count = (Row Total × Column Total) ÷ Grand Total.
  • df = (rows − 1)(columns − 1).

Linear Regression:

  • Tests for a linear relationship between two quantitative variables.
  • H₀: β = 0.
  • Hₐ: β ≠ 0 (or > 0, < 0).
  • Check LINER: Linear, Independent, Nearly Normal residuals, Equal variance, random sample.
  • Test statistic = (slope) ÷ (standard error).
  • df = n − 2.
  • Use LinRegTTest.
