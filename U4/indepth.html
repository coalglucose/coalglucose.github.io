Unit 4: Probability

DEFINITION & MISCONCEPTIONS

Probability is generally understood to be likelihood, and we frequently say things like “there’s a 0.5 probability a fair coin will land on heads.”

More rigorously, the probability of an event is the proportion of times it would occur over a loooong series of repetition. In the short run, it’s completely unsurprising to not have exactly 50% of your coin flips to be heads. But as we flip the coin over and over and over, we would see the ratio of heads to total flips converge to 0.5. This is the essence of the law of large numbers, probability refers to results in the long run, with many repetitions.

It is important to internalize that distinction…

> “I will get exactly 5 heads if I flip this coin 10 times.”

This falls into the myth of short-run regularity, a common misconception that (falsely) applies the concept of probability to the short-run.

> “I got 5 heads in a row, the next flip must be tails.”

This falls into the myth of the “law of averages”, which (incorrectly) assumes individual outcomes are affected by past results.

TERMS & NOTATION

Let us first introduce some notation and terms. For event A,

P(A) = probability of event A

Then, if we also have event B…

P(A|B) = probability of event A occurring GIVEN event B has already occurred.

P(A∩B) = P(A and B) = probability of event A and B occurring

P(A∪B) = P(A or B) = probability of event A or B occurring*

* It’s a Boolean or. “A or B” can be just A or just B or both.

You might recognize the ∩ (intersection) and ∪ (union) symbols from set theory.

There are two special cases of A and B to discuss.

P(A|B) = P(A): A has the same probability of occurring regardless of whether B occurs or not. In other words, B’s occurrence (or lack thereof) has no effect on A; A is independent of B.

P(A∪B) = 0: it’s impossible for A and B to happen at once. The events are mutually exclusive (disjoint). One event’s occurrence (or lack thereof) does have an effect on the other; if A happens, B definitely didn’t and vice versa

GENERAL RULES

P(AC) = 1 - P(A)

C stands for complement, this is just the probability of A not occurring

P(A or B) = P(A) + P(B) - P(A and B)

        For disjoint events, since P(A and B) = 0, P(A or B) = P(A) + P(B)

        Also, see Inclusion–exclusion principle - Wikipedia 

P(A|B) = P(A and B) / P(B)

        Remember what P(A|B) is: P(B) * P(A|B) = P(A and B) -> P(A|B) = P(A and B) / P(B)

CONTINUOUS RANDOM VARIABLES

A continuous random variable X takes all the values in an interval, so its probability distribution is described with a density curve (recall U1).

DISCRETE RANDOM VARIABLES

A discrete random variable X will have a countable number of possible values (so no decimal frequencies). The probability distribution of X lists the probability of X taking a certain value.

The expected value and variance of X are conceptually the same as the mean and variance of distributions we’ve seen before, just with probabilities involved.

        Expected value: E(X) = μ = Σxipi

        Variance: Var(X) = σ2 = Σ(xi - μ)2 * pi

We can also transform and combine random variables.

If we want to transform X into Y via Y = aX + b,

        E(Y) = a*E(X) + b

        Var(Y) = a*Var(X)

Remember what variability is: a measure of spread. It doesn’t matter where the expected value is, just how far all the other values are from it. Furthermore, when you combine two variables like X - Y

        E(X-Y) = E(X) - E(Y)

        Var(X-Y) = Var(X) + Var(Y)

Doesn’t matter how you combine the variables, stuff is getting more disordered and spread out so the variances always add.

THE BINOMIAL DISTRIBUTION

There are two types of probability experiments we’ll cover in this unit. The first is a binomial (Bernoulli) experiment, which satisfy the following conditions (BINS):

        Each trial has a binary outcome: either it is a success or it is a failure

        Each trial has outcomes that are independent of each other

        There is a fixed number of trials every time the experiment is run

        The probability of success per trial is the same

If trials are not explicitly stated to be independent of each other, we use the 10% Rule: we can assume independence of trials for outcomes in a sample if they make up 10% or less of the entire population.

Establishing the other conditions are met is trivial, you just kinda state they are and mention the specific values.

Just like in U2, you must have a “Let” statements before referencing variables.

Typically people will use

        n = number of trials

        p = probability of success; so 1-p = probability of failure, often denoted as q

        X = number of successes

For a binomial distribution

E(X) = μ = Σxipi

Var(X) = npq;

If you are familiar with combinatorics, you may think of the probability of X taking a certain value (k) to be

P(X=k) = (n choose k) * p^k * q^(n-k)

Alternatively, you could use the binompdf and binomcdf on a handheld calculator.

We may also use z-scores if the binomial distribution is approximately normally distributed, and we will know that’s the case if it satisfies the Success/Failure Condition:

        if np >= 10 and nq >= 10, the distribution is approximately normally distributed

THE GEOMETRIC DISTRIBUTION

The last distribution covered in this unit is the geometric distribution, which gives the probability of a number of Bernoulli trials until the first success.

In a geometric distribution

E(X) = μ = 1/p

Remember: p = success/total trials, so we expect about 1 in p trials to be a success. Then, we would expect to run p trials on average before our first success.

Var(X) = σ2 = p / (q2)

There is a genompdf and genomcdf function on the calculator, but the combinatoric formula is

P(X=k) = q^(k-1) * p
