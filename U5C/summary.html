General Rules:

  • Compare the difference between two population parameters.
  • Use a let statement for both population parameters.

Dependent (Matched Pairs) t-Test:

  • One sample of differences (paired data).
  • H₀: μd = 0.
  • Hₐ: μd ≠ 0 (or > 0, < 0).
  • Assumptions:
  • Random sample
  • Independent pairs (10% condition)
  • Nearly Normal differences (or n ≥ 30)
  • Use T-Test on the list of differences.

Two-Sample Mean t-Test:

  • Compares two population means.
  • H₀: μ₁ = μ₂ (or μ₁ − μ₂ = 0).
  • Hₐ: μ₁ ≠ μ₂ (or > 0, < 0).
  • Assumptions:
  • Random samples
  • Independent observations
  • 10% condition
  • Nearly Normal populations (or both n ≥ 30)
  • Samples are independent
  • Use 2-SampTTest.

Two-Sample Proportion z-Test:

  • Compares two population proportions.
  • H₀: p₁ = p₂ (or p₁ − p₂ = 0).
  • Hₐ: p₁ ≠ p₂ (or > 0, < 0).
  • Assumptions:
  • Random samples
  • Independent observations
  • 10% condition
  • Large Counts condition (all expected successes and failures ≥ 10)
  • Samples are independent
  • Use 2-PropZTest.
